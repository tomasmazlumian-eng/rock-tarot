# Rock Tarot — Standalone Website

## Quick 2-Minute Setup for Vercel (100% Free)

1. Create a free account at [Vercel](https://vercel.com) and [GitHub](https://github.com).
2. Create a new GitHub repository called `rock-tarot`.
3. Upload all the files from this folder to your GitHub repo.
4. On Vercel, click **Add New... > Project**, select your `rock-tarot` repo, and click **Deploy**.
5. Your website is live in 60 seconds with your own clean URL (e.g. `https://rock-tarot.vercel.app`)!

### Running Locally on Your PC / Mac:
```bash
npm install
npm run dev
```
